# Determinize site: design preview

Static mockups of two design directions for the landing page and the simulator of [determinize](https://github.com/julesjacobs/determinize). Temporary; the repository will be deleted once a direction is chosen.

- `a/`: direction A, the paper's figure
- `b/`: direction B, given the G draws

## Fonts

The `fonts/` folders hold subsets of fonts under the SIL Open Font License 1.1; their licences are in `licenses/`.

- Libertinus Serif 7.051 and Inconsolata 3.001 (direction A).
- Atkinson Hyperlegible Next 2.001 (direction B).
- "Determinize Mono" (direction B) is a subset of JuliaMono 0.63.2. JuliaMono's licence reserves the name "JuliaMono", so the modified (subset) version carries another name.
