Determinize

Type inference finds the random draws in a probabilistic program that can be replaced by the means of their distributions. For domain-safe programs of type float[E], the replacement keeps the expected output and does not increase its variance.

What is proved

For a closed program e of type float[E] that is domain-safe, and its determinization:

  1. it returns with the same probability as e (output mass preservation);
  2. if e returns with positive probability and its expectation is defined, the determinized program's expected output given that it returns equals e’s, possibly infinite (expectation preservation);
  3. if e returns with positive probability and has a finite second moment, its variance given that it returns is at most e’s (variance non-increase);
  4. for almost every terminating G trace, it returns e’s mean output given that trace (tracewise soundness).

Inference fails only when no assignment of modes agrees with the modes written in the program. Otherwise it returns the assignment with the most E draws: every draw that some valid assignment marks E is marked E (inference correctness). Domain safety and integrability are premises; typing does not establish them.
